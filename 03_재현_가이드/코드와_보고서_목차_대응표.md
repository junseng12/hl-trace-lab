# 코드와 보고서 목차 대응표

이 문서는 보고서의 두 핵심 실험과 공개 저장소 코드를 대응시킨다.

```text
실험 1, 전체 자산 이동 8경로 연결
  └─ 01_자산이동_8경로

실험 2, HyperCore 오더북 기반 가치 이전 추적
  └─ 02_오더북_가치이전
```

## 2장, 자산 이동 경로와 공개 아티팩트 검증

| 보고서 절 | 재현 대상 | 저장소 위치 | 주요 출력 |
|---|---|---|---|
| 2.1 검증 범위와 공개 관찰 데이터 | Core API, EVM RPC, System TX RPC, 외부 Explorer, 브리지 상태의 역할 | `01_자산이동_8경로/README.md`, 경로별 스크립트의 공통 조회 모듈 | 실제 조회 URL, 입력값, 원자료와 조회 시각 |
| 2.2 전체 자산 이동 8경로 | 외부·Core·EVM 사이의 8경로를 각각 재조회 | `01_자산이동_8경로/route01_external_to_core.py`부터 `route08_hyperevm_to_external.py` | 경로별 증거 JSON과 보수적 판정 |
| 2.3 핵심 추적 공백과 보완 | 공통 hash 부재, System TX 가시성, 반복 전송 후보 충돌 | 경로 4·5 추적기, 공통 후보 매칭 로직 | `candidateCount`, `timeDeltaMs`, 표준 RPC 가시성, `AMBIGUOUS` 판정 |

## 공개 저장소에 포함할 것과 제외할 것

포함:

- 읽기 전용 추적 코드
- 빈 `.env.example`
- 공개 주소와 공개 TX 식별자로 만든 예시 결과
- 실행 명령과 판정 기준

제외:

- `.env.local`
- Master·Agent 개인키와 시드 문구
- API 인증 헤더
- 개인키가 포함된 터미널 캡처와 로그
- 거래 실행을 위해 사용한 실제 비밀 설정 파일

비밀값은 사용자가 로컬 파일에 직접 입력하고, 코드와 문서에는 변수명만 남긴다.
